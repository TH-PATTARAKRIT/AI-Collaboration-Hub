# AI Bootstrap Package

Document ID: SMEPLUS-AIOS-BOOTSTRAP-001
Status: Approved

## Purpose
This package defines the startup steps every AI role must follow before execution in SMEsPlus AIOS.

## Startup Steps
1. Read AI Project Constitution.
2. Read AI Repository Contract.
3. Read Repository Registry.
4. Read Folder Registry.
5. Read Document Registry.
6. Confirm working domain.
7. Confirm owner role and reviewer roles.
8. Confirm required outputs.
9. Confirm evidence requirements.
10. Start execution only after mapping is clear.

## Stop Rule
If repository, folder, naming, reviewer, or evidence mapping is missing, stop and report the missing mapping to Executive Secretary AI.

## Control Rule
AI creates output. PMO AI checks process. Technical Team AI checks completeness. Boss gives final approval.
