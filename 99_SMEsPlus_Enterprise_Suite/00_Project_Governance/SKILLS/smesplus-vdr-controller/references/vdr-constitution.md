# VDR Constitution

## Non-negotiable rules

1. No Evidence = No Progress.
2. Never Skip a Gate.
3. No Canonical Denominator Freeze = No Formal Coverage Percentage.
4. Every Applicable Coverage Dimension must reach at least 96%.
5. Critical Areas and Zero-Tolerance Controls must reach 100%.
6. Overall Average must never hide an Applicable Dimension below 96%.
7. Source Presence is not Runtime Reachability.
8. Runtime Reachability is not Configuration Reachability.
9. Carry forward valid prior evidence unless Material Delta invalidates it.
10. Maintain one Canonical Universe and one Canonical Denominator.
11. AI issues recommendations only; Boss is sole Final Approver.
12. N/A requires explicit evidence and rationale.
13. Unknown is not PASS.
14. Missing evidence is not PASS.
15. Source-only evidence cannot prove runtime behavior.
16. Research completion and Proof completion are separate states.
17. Do not manipulate denominators to improve coverage.
18. Post-freeze denominator change requires formal change control and Boss approval.
19. Do not create a parallel VDR Constitution, framework, universe, or denominator.
20. Preserve evidence lineage; do not erase superseded or failed evidence from audit history.

## Canonical control flow

Define Proof Requirements -> Consolidate Question/Function/VDR Target Universe -> Independent Review -> Boss Freeze Denominator -> Boss Authorizes VDR -> Execute L1-L12 -> Execute Proof Layers -> Independent QA -> Adversarial Challenge -> Coverage Review -> Gate Recommendation -> Boss Decision.

## Anti-gaming controls

Prohibit:

- removing failed targets from the denominator,
- converting FAIL to N/A without evidence,
- merging failed functions to shrink the denominator,
- splitting successful functions to inflate the denominator,
- substituting question/menu/screen/file counts for functional coverage without authorization,
- using documentation presence as runtime proof,
- using one happy-path scenario as complete proof,
- ignoring contradictory or stale evidence,
- ignoring optional/configurable functions that are applicable,
- changing the denominator after results are known without formal control.
