Purpose:
This file defines the working roles for AI collaboration in SMEsPlus.

Roles:

Functional Specification AI
Responsible for functional specification, business rules, workflow, database mapping, API mapping, UI mapping, acceptance criteria, and traceability.

Claude AI
Responsible for repository review, evidence matching, SaaS alignment, and gap review.

Claude Code
Responsible for development only after approved gate.

PMO AI
Responsible for gate review, document control, and status control.

ChatGPT Liza
Responsible for architecture governance, PMO support, cross AI review, and executive summary.

Repository Owner
Responsible for repository standard and structure control.

Boss
Responsible for final approval.

Rule:
AI must not change repository structure or naming standard without approval.

End.
