# Allowed and Prohibited Data Boundary

## Allowed
- Table names
- Column names
- Data types
- Foreign key relationships
- Index names
- Aggregated object counts
- Module-level summaries
- Diagrams
- Redacted logs

## Prohibited
- Customer names and contact values
- Employee personal data
- Payroll and salary values
- Bank account values
- Passwords and hashes
- API keys and tokens
- Session data
- Attachment contents
- Unmasked email or phone values
