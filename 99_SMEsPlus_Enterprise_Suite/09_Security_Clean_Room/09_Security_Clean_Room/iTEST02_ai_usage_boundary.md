# AI Usage Boundary

## AI May Receive
- Schema-only metadata
- ERD summaries
- object counts
- masked evidence
- governance notes
- non-sensitive logs

## AI Must Not Receive
- raw dump files
- restored row data
- employee data
- bank data
- credentials or tokens
- attachment content
- unmasked customer data

## Required Prompt Header
This task uses metadata only. Do not request or infer actual sensitive values.
