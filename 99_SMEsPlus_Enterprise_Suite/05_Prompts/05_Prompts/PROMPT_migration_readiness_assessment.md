# Prompt: Migration Readiness Assessment

Assess whether the iTEST02 database package is ready for migration rehearsal.

## Evaluate
- restore repeatability
- object count reconciliation
- extension availability
- masked data availability
- module owner approval
- rollback procedure
- audit trail completeness

## Output
1. readiness score from 0 to 100
2. blocking issues
3. non-blocking issues
4. required evidence
5. go or no-go recommendation
