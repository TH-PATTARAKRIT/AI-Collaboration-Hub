# Prompt: ERD by Module Generation

Use schema metadata to create a readable ERD per business module.

## Target Modules
- Accounting and Finance
- Sales and CRM
- Inventory and Purchase
- HR and Payroll
- Manufacturing and Maintenance
- Website and eCommerce
- AI and Knowledge

## Required Output
For each module:
1. key tables
2. primary relationships
3. integration points
4. sensitive data notes
5. migration dependencies

## Constraint
Do not generate a single mega-ERD. Use small diagrams with 5-12 entities each.
