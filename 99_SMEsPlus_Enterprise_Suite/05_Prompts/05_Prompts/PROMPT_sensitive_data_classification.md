# Prompt: Sensitive Data Classification

Analyze the following schema metadata and classify sensitive data risk.

## Classification Labels
- PUBLIC
- INTERNAL
- CONFIDENTIAL
- RESTRICTED
- SECRET

## Risk Categories
- PII
- HR
- Payroll
- Banking
- Credentials
- Tokens
- Attachments
- Audit logs
- AI embeddings or vectorized content

## Required Output
| Table | Column | Category | Classification | Risk | Recommended Control | Evidence Required |
|---|---|---|---|---|---|---|

## Strict Rule
Do not infer or reconstruct actual values. Work only from metadata.
