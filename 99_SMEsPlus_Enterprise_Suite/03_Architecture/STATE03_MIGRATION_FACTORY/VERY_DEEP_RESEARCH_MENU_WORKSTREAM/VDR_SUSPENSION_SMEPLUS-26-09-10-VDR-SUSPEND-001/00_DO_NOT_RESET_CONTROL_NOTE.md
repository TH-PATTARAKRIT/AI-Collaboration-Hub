## Why this note exists

**Previous failures are part of the learning history**, and in this programme they are the more
instructive part.

- A retraction that was **itself refuted**, whose disproof sat unread inside the same frozen package.
- Six coverage dimensions graded on the register's **own authored columns**, zero exceptions in 5,074 rows.
- A control built to prevent self-referential measurement that was **itself self-referential and could not fail**.
- A predicate that returned a clean zero because a word boundary cannot match inside an identifier.
- A population that turned out to be **a fifth of its domain**.

**Every one of those is only visible because the failed round was kept.** Delete the failures and the
programme relearns them.

## What preservation means here

| | |

| Retracted work | **evidence** |
| Refuted work | **evidence** |
| Rejected instruments | **evidence** |
| False positives, false negatives, false duplicates | **evidence** |
| Contradictions recorded open | **evidence, and deliberately not closed** |
| Partial and unverified output | **evidence, labelled as such** |

**Nothing in this programme has been deleted, and nothing may be.**
