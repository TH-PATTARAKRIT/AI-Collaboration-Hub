# 9. PRIMARY VDR — INTERNAL MULTI-PASS MODEL

Execute multiple passes inside one governed Primary VDR cycle.

Minimum passes:

### PASS A — Normal Process / Happy Path
Understand purpose, actors, lifecycle, normal sequence, state changes and expected outcome.

### PASS B — Data / State / Validation
Fields, identity, defaults, mandatory rules, derived values, state machine, validation, effective dating and immutable facts.

### PASS C — Roles / Controls / Audit
Permissions, approvals, segregation of duties, override controls, evidence, audit history and non-repudiation requirements.

### PASS D — Cross-Module / Cross-Domain
Every upstream/downstream handoff, source of truth, ownership boundary, event / interface and reconciliation obligation.

### PASS E — Exception / Failure / Reversal / Concurrency
Cancel, return, reject, reverse, retry, duplicate, concurrent edits, partial completion, race condition, failed integration, failed posting and recovery behavior.

### PASS F — SaaS / Tenant / Multi-Company / Company Context
Visibility, ownership, isolation, company scope, organization root, branch, cross-company permissions and forbidden leakage.

### PASS G — Migration / Historical / Reconciliation
Legacy import, historical records, references to inactive entities, opening data, cutover, backdated changes, reconstruction and end-to-end proof.

### PASS H — UX / Menu / Field / Interaction Implications
What users must see/do, state-driven visibility/editability, actions, warnings, errors, drilldowns and what must remain background behavior rather than become a menu.

### PASS I — Adversarial Missing-Scenario Attack
Ask: `What real operating situation would make this research incomplete or wrong?`
Generate explicit edge scenarios and attempt to break the assumed model.

### PASS J — Contradiction / Evidence Reconciliation
Reconcile conflicting sources, assumptions, prior decisions and cross-domain semantics. Do not hide contradictions.

Additional specialist passes may be added for Accounting, Tax, Inventory Valuation, Security, Privacy, API, Performance, Migration, Regulatory or other material subjects.
