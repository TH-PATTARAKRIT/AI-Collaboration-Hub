# 05_QUARANTINE

Purpose: Isolate findings that must not propagate into Team B design input.

Quarantine examples:
- Vendor-specific algorithms
- Source-code-derived technical behavior
- ORM-specific behavior
- Internal hooks/methods/states
- Proprietary module interactions
- Vendor-specific schema/optimization patterns
- Unverified AI inference with design impact

Status: QUARANTINED / NOT ELIGIBLE FOR TEAM B HANDOFF.

A quarantined concept may be reconsidered only when independently supported by regulatory, industry, mathematical, customer-business, or cross-vendor evidence.
