## How to read this register

- Statuses: `VERIFIED-OFFICIAL` = stated by an official primary source I read; `OFFICIAL-SUMMARY-ONLY` = official guide/calendar/summary page, not the provision text; `UNVERIFIED` = no official source read (or only secondary); `CONFLICT` = official or seed sources disagree (note given).
- `Read` column: **R** = the full text was extracted/viewed raw (PDF text extracted locally, or Royal Gazette pages viewed as images); **S** = the page was read through the fetch tool's summarising step (paraphrase of the official page, not byte-exact text). S-only statements are official-page-derived but should get a second raw read before any reliance (see Limits).
- `Seed` column compares with the verifier's seed register (`/private/tmp/claude-501/seed/STATE03_THAILAND_STATUTORY_SOURCE_REGISTER.md`, all rows SECONDARY-CONFIRMED, read-only, not edited): `CONFIRMS`, `PARTIAL`, `CONFLICTS`, or `n/a` (no seed row). Seed topic names are in square brackets.
- `Risk` = LAST-CHANGE-RISK (High where rates/deadlines change often).
- Sources marked `SECONDARY — NOT VALIDATING` appear only in the source table and never support a verified status.
- Paraphrase only; no statute text reproduced.
