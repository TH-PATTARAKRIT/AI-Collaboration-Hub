## KEY CHAIN SEQUENCE

```
PO confirm → button_confirm()
  → button_approve()                              [purchase_stock override]
    → state = 'purchase', date_approve = now
    → _create_picking()
      → _prepare_picking()                        [builds header dict]
      → StockPicking.create()                     [picking state=draft]
      → order_line._create_stock_moves(picking)
        → _prepare_stock_moves() → _prepare_stock_move_vals()
        → stock.move.create(values)
      → moves._action_confirm() → state=confirmed
      → moves._action_assign()  → reserves stock

Receipt validate → picking.button_validate()
  → stock_account override of _action_done()
    → moves_in._set_value()                       [computes value]
    → moves._create_account_move()
      → _should_create_account_move() check
      → account.move.create() + _post()           [SVL journal entry posted]
  → qty_received updated (via stock_moves method)
    → qty_to_invoice recomputed
    → invoice_status → 'to invoice'

Bill creation → action_create_invoice()
  → _prepare_invoice()                            [move_type='in_invoice']
  → line._prepare_account_move_line() per line
  → account.move.create()                         [draft vendor bill]
  → [user reviews and posts] action_post()/_post()
    → state='posted'

AP reconciliation → payment.action_post()
  → destination_account = partner.property_account_payable_id
  → account.move.line.reconcile()
    → _reconcile_plan() → account.partial.reconcile created
```
