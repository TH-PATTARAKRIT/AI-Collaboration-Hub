## Key Architecture Notes

- `mrp_maintenance` module is **ABSENT** from Community 19.0 — no manufacturing workcenter integration.
- Preventive recurrence uses in-request fields (`repeat_interval`, `repeat_unit`, `repeat_type`, `repeat_until`) rather than equipment-level period fields; the trigger is stage completion in `write()`.
- MTBF/MTTR computation lives in `maintenance.mixin` (abstract), so it can be reused by any model that inherits it (currently `maintenance.equipment` only in Community).
- A `module_maintenance_worksheet` Boolean in `res.config.settings` suggests an optional `maintenance_worksheet` module exists but is not part of Community core.
