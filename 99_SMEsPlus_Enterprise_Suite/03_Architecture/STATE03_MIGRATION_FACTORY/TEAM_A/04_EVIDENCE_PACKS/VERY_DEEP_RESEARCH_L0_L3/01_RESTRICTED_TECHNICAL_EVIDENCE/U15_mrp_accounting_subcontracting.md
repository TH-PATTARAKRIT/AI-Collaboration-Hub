## CAP-U15-01 Manufacturing order cost computation and by-product cost allocation

**Function-ID(s):** `MFG-F04` (MO cost computation), `MFG-F02` (finished-goods valuation, only the claims about the finished unit value), `BRP-F08` (by-products, cost-share claims), `BRP-F04` (work-centre cost per hour, work-order costing claims).

**D1 — Business purpose & process semantics.** When a manufacturing order is posted, the finished product (and by-products) must carry a cost that reflects consumed component value, work-centre time and an optional extra unit cost. In 19 this is a *price-stamping step*: `mrp_account` sets `price_unit` on the finished and by-product moves, and stock valuation then reads it as the move value. Finished goods of a **standard-cost** product are stamped at `standard_price` (actual spend is not absorbed); FIFO/average products absorb actual spend. By-product cost allocation is a percentage (`cost_share`) per BoM by-product line, default zero (full cost stays with the main product). This resolves pilot gap GAP-BRP-09 and the MFG-F04 note "work-center cost-rate mechanics not evidenced": the rate is one hourly figure on the work centre, stamped on the work order at finish. C001, C007, C020, C021, C018, C030, C037, C040

**D2 — Architecture / data / object relationships.**

- `stock.move.price_unit` of finished/by-product moves is the carrier; `stock.move.value` is derived through `_get_value_from_production` (mrp_account) in the receipt value chain of stock_account C022, C023.
- Constraints on shares: on MO (`_check_byproducts`) and on BoM (`_check_bom_lines` per variant) C025, C026, C027, C028.

**D3 — Source / technical / workflow logic.**
State (cost): `raw moves picked -> raw moves done (value set) [_post_inventory -> _action_done]`; `raw done -> work-order durations fixed (0 -> expected; cancelled -> 0) [_post_inventory]`; `durations fixed -> price_unit stamped on finished/by-product moves [_cal_price]`; `price stamped -> finished moves done (valued from price_unit) [moves_to_finish._action_done]`.
