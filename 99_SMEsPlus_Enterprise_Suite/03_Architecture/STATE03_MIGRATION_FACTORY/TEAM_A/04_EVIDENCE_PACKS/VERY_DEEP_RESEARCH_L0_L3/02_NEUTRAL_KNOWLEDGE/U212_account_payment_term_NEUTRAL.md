## Migration Flags Summary

| Flag | Description |
|------|-------------|
| NEW-v16 | Field or method introduced in version 16; absent in v14/v15 databases — additive migration required |
| BREAKING-v16 | Balance line type removed from selection; v14/v15 records with value type balance must be converted to percent |
| CHANGE-v16 | Day-of-month scheduling restructured; old integer day_of_the_month field replaced by delay_type with days_next_month character field |
| COUNTRY-DRIVEN | Value automatically set by country code at runtime; no manual migration of stored values required |
| MULTI-CO | Cross-company sharing controlled by optional company field and parent-of domain check |
