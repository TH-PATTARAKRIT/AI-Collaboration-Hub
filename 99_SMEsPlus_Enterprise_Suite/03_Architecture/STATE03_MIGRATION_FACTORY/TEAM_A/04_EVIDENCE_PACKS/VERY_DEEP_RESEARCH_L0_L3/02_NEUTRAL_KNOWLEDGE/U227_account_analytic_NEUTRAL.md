## Summary Notes

- **Flat accounts, hierarchical plans**: accounts have no parent; plans use path-based tree.
- **Dynamic columns**: each root plan creates a new DB column on tracking lines; sub-plans create computed groupby fields.
- **Mandatory = 100%**: "mandatory" applicability means the distribution to that plan must sum to exactly 100%.
- **JSON key format**: `"id1,id2"` keys allow cross-plan combined entries.
- **validate_analytic context**: validation is opt-in via context key, not automatic on every write.
- **BREAKING v16+ migration**: `analytic_account_id`, `analytic_tag_ids`, `account.analytic.tag` all removed.
