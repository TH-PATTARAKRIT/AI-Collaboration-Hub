## Migration Flag Reference

| Flag-ID | Description |
|---------|-------------|
| MIG-01 | `hr.contract` (v16/v17) replaced by `hr.version`; all contract fields now on version record |
| MIG-02 | `address_home_id` (home address partner link) removed; replaced by discrete private address fields |
| MIG-03 | `resource.calendar.attendance.date_from` / `date_to` removed; attendance is purely weekday-based |
| MIG-04 | `resource_calendar_id` on employee is non-stored in v19; filter using `current_version_id` join |
| MIG-05 | `job_id`, `department_id`, `address_id` live on `hr.version`; accessed via `_inherits` delegation |
| MIG-06 | `hr.employee.public` is a SQL VIEW (not a table) joining employee and version |
