# U80 Neutral Knowledge — Stock Valuation AVCO/FIFO
> NEUTRAL LAYER — no source paths, no class/method names, no file extensions, no snake_case, no backticks

| NR-ID | Statement |
|---|---|
| NR-U80-001 | Odoo 19 Community contains a dedicated model for recording product value history; it is separate from the stock move itself and is used for both manual value overrides and standard price change audit trails. |
| NR-U80-002 | The product value history record holds a monetary value field, references to the product, the optional lot or serial number, and the optional stock move; it does not contain a quantity field — quantity context is inferred from the referenced move or product. |
| NR-U80-003 | When a product value record is created linked to a stock move, the system immediately triggers recomputation of that move's monetary value. When created linked to a product without a move, it triggers recomputation of the product standard price. |
| NR-U80-004 | The perpetual valuation sequence begins when a stock transfer is confirmed: outgoing moves are valued first (before the transfer is finalised) so that the cost pool reflects quantities still available; incoming moves are valued after the transfer completes. |
| NR-U80-005 | For Average Cost (AVCO) products, outgoing moves are valued at the current standard price multiplied by the moved quantity at the moment of validation. The standard price is not consumed from a historical stack. |
| NR-U80-006 | For FIFO products, outgoing moves are valued by consuming the monetary cost of the oldest unreleased incoming quantities in sequence, oldest receipt first. The cost per unit may differ for each layer consumed if purchase prices varied. |
| NR-U80-007 | The FIFO cost stack is not a stored table of layers; it is dynamically reconstructed at valuation time by querying historical incoming moves and calculating how much of each remains unconsumed based on current stock quantity. |
| NR-U80-008 | For FIFO, when outgoing quantity exceeds on-hand stock (negative stock scenario), the shortfall is valued at the unit price of the most recent incoming move. This prevents zero-value entries when selling before receiving. |
| NR-U80-009 | After an outgoing FIFO move is validated, the product standard price is updated to the value-weighted average of the remaining unexhausted incoming layers, providing a meaningful cost reference even though FIFO costing is primary. |
| NR-U80-010 | The AVCO standard price update uses an incremental formula when only one receipt is processed: new average cost equals the sum of existing stock value and the new receipt value, divided by the new total quantity. This is the standard weighted average formula. |
| NR-U80-011 | When stock quantity is zero or negative before a receipt, the AVCO incremental path cannot use a rolling average; the average cost resets to the unit price of the incoming receipt instead. |
| NR-U80-012 | For customer returns (goods returned from customer), the return receipt is valued at the pro-rated value of the original outgoing delivery, not at current standard price. This ensures the inventory is restored at the cost it left at. |
| NR-U80-013 | There is no retroactive recomputation of prior period product value records when a return is processed; only the new return move receives a value, and the product standard price is updated going forward. |
| NR-U80-014 | A journal entry is generated for a stock move only when four conditions are all true: the product is storable, the move represents a valued flow, at least one of the source or destination locations carries an accounting counter-account, and the product category uses perpetual (real-time) valuation. |
| NR-U80-015 | For a receipt from a vendor: the journal entry debits the stock valuation account and credits the counter-account attached to the source location (typically a goods-received-not-invoiced account). |
| NR-U80-016 | For a delivery to a customer: the journal entry debits the counter-account attached to the destination location (typically a cost-of-goods-sold account) and credits the stock valuation account. |
| NR-U80-017 | For a scrap operation: a stock move is generated from the internal storage location to the scrap (inventory-loss) location; because the scrap location is not a valued location, the move is treated as an outgoing move; the journal entry debits the expense account configured on the scrap location and credits the stock valuation account. |
| NR-U80-018 | The perpetual versus periodic valuation mode is controlled by a company-dependent setting on the product category; when set to perpetual, journal entries are generated automatically at move confirmation; when periodic, no automatic entries are created and inventory value is adjusted only at period close. |
| NR-U80-019 | The costing method (standard price, average cost, or FIFO) is also a company-dependent setting on the product category and is inherited by all products in that category; changing it triggers a stock revaluation for affected products. |
| NR-U80-020 | For scrapped AVCO products, the scrap is valued at the current standard price (which equals the running weighted average cost) at the time of scrapping. |
| NR-U80-021 | For scrapped FIFO products, the scrap move consumes the oldest unexhausted FIFO layers in the same way as a regular delivery, so the scrap is valued at historical acquisition cost, not at current market or average price. |
| NR-U80-022 | The remaining unconsumed FIFO value for each incoming move is a computed quantity derived from the difference between the original incoming quantity and the total outgoing quantities attributed to that layer; it is not stored as a static field but recalculated dynamically. |
| NR-U80-023 | A single accounting journal entry is created for the entire batch of stock moves confirmed in one operation; individual move values are collected as journal entry lines within that single entry. |
| NR-U80-024 | The journal entry is posted (confirmed) immediately at move validation; it is not held in draft. The stock journal configured on the company is used as the accounting journal for all stock valuation entries. |
