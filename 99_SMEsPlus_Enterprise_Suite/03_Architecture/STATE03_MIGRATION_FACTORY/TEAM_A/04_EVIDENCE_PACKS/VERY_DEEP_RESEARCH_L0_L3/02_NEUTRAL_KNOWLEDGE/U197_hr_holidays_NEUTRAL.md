## Summary of Migration Flags

1. **No draft state** (C01, C02): `hr.leave` has no `draft` state in v19. Records created directly in `confirm`.
2. **date_from/date_to computed** (C03): `request_date_from`/`request_date_to` are the input fields; `date_from`/`date_to` are stored computed results.
3. **allows_negative new** (C13): Overdraft feature on `hr.leave.type` is new; v16 sources will lack this column.
4. **allocation_type readonly** (C14): Cannot be changed post-creation; migration must set correctly on import.
