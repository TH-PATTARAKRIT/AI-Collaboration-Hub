## A. Capabilities
1. When an alternative RFQ is created from an RFQ that was generated by a sale order (service product flagged to be bought, "Subcontract Service"), each copied order line keeps the link to the origin sale order item (purchase_requisition_sale/wizard/purchase_requisition_create_alternative.py:10-16). This is the only behaviour added; it is not conditional beyond the parents being installed.
