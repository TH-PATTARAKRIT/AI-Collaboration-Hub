# 01_SOURCE_REGISTRY

Purpose: Register every research/source asset before analysis.

Required fields per source:
- Source ID
- Source Type
- System / Vendor / Version
- Domain
- Access Authorization / Owner
- Storage Location (reference only)
- SHA-256 / Checksum where applicable
- Provenance Class P1-P8
- Confidentiality / Restriction
- Research Status
- Evidence Reference

Raw dumps, proprietary source archives, credentials, and restricted customer data must not be committed here.
