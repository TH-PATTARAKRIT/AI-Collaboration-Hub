## 1. `D-5`, Retrieved

> **`D-5` — the accounting-event identity (`P11-B-02`): introduce a layer-3 event object, or not.** *"No research closes it; seven recorded symptoms across four programmes reduce to it."* Decider: **Boss.**

Every kernel element below is measured against it.

## 2. The Three Elements, Classified

| Element | Classification | Basis | Depends on |
|---------|---------------|-------|------------|
| **`K-1` Allocation convention library** | **SUPPORTED DESIGN CANDIDATE** | Two independent implementations of the same 30/360 arithmetic exist in the reference product with different normalisation; three allocation methods exist on one mechanism and two on another. The *duplication* is `FACT VERIFIED`; that a shared library is the right answer is a **design candidate**, not a fact | Nothing. Decidable independently of `D-5` |
| **`K-2` Correction algebra** | **SUPPORTED DESIGN CANDIDATE**, weakened | Four mechanisms exhibit four different correction behaviours — `FACT VERIFIED`. That they reduce to one algebra with policies is a candidate, and P10's own evidence **partly contradicts it**: in-flight modification differs by **domain lifecycle**, not by algebra. Three of four correction rows support the candidate; one does not | Nothing. Decidable independently |
| **`K-3` Attribution construction** | **FACTUAL COMMON SEMANTIC**, and the strongest of the three | Two unrelated mechanisms — deferral and depreciation — **independently implement the same attribution shape**, each in its own generator, neither in the shared posting layer. That is `FACT VERIFIED` and it is convergence of two independent implementations, not one code path observed twice | Nothing. Decidable independently |

## 3. What Each Element Is **Not** Dependent On

The prior round stated the kernel was *"sequenced after `D-5` and not independently decidable"*. That is **too strong**, and this matrix corrects it.

| Question | Answer |
|----------|--------|
| Does `K-1` need the event object? | **No.** A convention library takes a base, a window, a grid and a rule and returns amounts. It needs no event identity |
| Does `K-2` need it? | **Partly.** The algebra's three outcomes — stands, re-derived, catch-up delta — can be specified without an event object, but cannot be **enforced** without something to address |
| Does `K-3` need it? | **No.** It is a construction rule about which rows receive an attribution |
| What **does** need `D-5`? | The **recognition event** itself, and therefore the option that separates period from posting date structurally |

> **Corrected position: `K-1` and `K-3` are decidable now. `K-2` is specifiable now and enforceable after `D-5`. Only the event object waits on `D-5`.**
