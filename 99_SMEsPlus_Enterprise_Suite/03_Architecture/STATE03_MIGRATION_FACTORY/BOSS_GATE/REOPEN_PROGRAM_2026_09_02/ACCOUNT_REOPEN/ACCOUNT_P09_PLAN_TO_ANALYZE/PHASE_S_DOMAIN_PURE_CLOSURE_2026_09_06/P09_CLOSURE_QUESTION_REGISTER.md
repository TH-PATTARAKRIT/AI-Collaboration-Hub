This is **class B**, and the boundary matters: the root may well exist outside the bounded set, in locations this prompt forbids sweeping. **It is not a claim that the root does not exist, and it does not contradict a single finding built on it.**

What it does establish is narrower and still serious: **a reader who has only the published package cannot reproduce its principal population.** The programme's own rule — [[scope stated as a description]] — says a path set must be declared as a resolvable set, not described. The base package described.

**Disposition: `UNRESOLVED — SPECIFIC P09 EVIDENCE UNAVAILABLE`**, routed with the exact action needed to close it (`…OPEN_EVIDENCE…` item `OE-04`). No finding is withdrawn on this basis.
