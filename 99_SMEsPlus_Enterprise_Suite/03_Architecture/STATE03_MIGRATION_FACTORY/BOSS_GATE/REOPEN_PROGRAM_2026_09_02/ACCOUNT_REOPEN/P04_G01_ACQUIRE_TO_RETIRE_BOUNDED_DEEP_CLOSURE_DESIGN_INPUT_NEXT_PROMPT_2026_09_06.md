## 6. BOSS-APPROVED CONTROLLED DESIGN INPUTS — POLICY, NOT SOURCE FACT
Carry forward as Boss-approved SMEsPlus policy inputs:
- Asset Model primarily defines depreciation/accounting calculation policy, not production placement/routing/allocation.
- Equipment may exist without being a financial Asset.
- Work Center membership alone is NOT evidence of machine cost absorption.
- Target production causality: Routing -> Operation -> Equipment Actually Used -> Equipment Usage Cost -> MO/WIP/FG.
- Active-period depreciation: productive -> WIP/FG; non-productive -> named operational cause; no unclassified depreciation.
- Post-depreciation internal equipment usage may continue without residual-value cap while equipment remains operational.
- Financial residual book value is not consumed by internal managerial usage.
- Financial depreciation and managerial/internal usage allocation are separate truths.
- Off-Balance is an Account Type; off-balance double entries pair with off-balance, not directly with normal financial accounts.
- Productive allocation options: Machine Hour / Work Center Hour / Production Quantity; no mandatory default.
- Analytic Account / Analytic Distribution must not be omitted from non-production and management-cost design.
