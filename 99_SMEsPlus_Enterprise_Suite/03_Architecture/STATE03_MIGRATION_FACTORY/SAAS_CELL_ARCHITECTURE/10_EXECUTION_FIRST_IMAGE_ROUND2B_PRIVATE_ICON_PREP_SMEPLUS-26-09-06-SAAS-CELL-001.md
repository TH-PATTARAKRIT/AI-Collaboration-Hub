## 3. Proposed SMEsPlus Domain Icon Language — TEST ONLY

Principles:

- Recognition before Differentiation.
- Familiar metaphor first.
- One consistent outer icon container.
- One shared provisional SMEsPlus visual signature.
- Domain meaning must survive without color.
- Parent icon represents the domain, not one child document such as SO or PO.
- Icon must improve recognition; if it does not, remove it rather than force relearning.

Private icon hypotheses:

- Sales: document + outward action.
- Procurement: incoming action into a box/resource.
- Inventory: stored object + two-way movement to represent receipt, delivery and transfer rather than only stock balance.
- Manufacturing: process/gear + output object.
- Finance: ledger + verified balance/check.
