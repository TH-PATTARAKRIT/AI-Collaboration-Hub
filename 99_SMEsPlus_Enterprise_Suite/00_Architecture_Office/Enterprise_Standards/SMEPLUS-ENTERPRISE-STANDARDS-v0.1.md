# SMEPLUS Enterprise Standards v0.1

Rules:
- No Evidence = No Final Claim
- No Requirement ID = No Jira Task
- No Business Rule = No Claude Implementation
- No UAT = No Done
- No Review Gate = No Merge
- No Security Review = No Release

Standard Flow:
Requirement → Business Rule → Screen/API/Data → Jira → Claude → UAT → Review Gate → Release
