# Review Checklists

## Purpose
Provide systematic checklists for architectural reviews and quality gates.

## Checklists
- **ARG_CHECKLIST.md** - Architecture Review Gate checklist
- **Security_Review_Checklist.md** - Security compliance verification
- **Performance_Review_Checklist.md** - Performance standards verification
- **Integration_Review_Checklist.md** - Integration architecture review

## Usage
1. Use checklist before submitting for review
2. Verify all items in checklist
3. Document any exceptions
4. Submit with evidence of compliance
5. Reviewer verifies completion

## Gates
- **Design Gate**: Before implementation
- **Code Review Gate**: Before merge
- **Integration Gate**: Before deployment
- **Security Gate**: Before production
- **Release Gate**: Before go-live
