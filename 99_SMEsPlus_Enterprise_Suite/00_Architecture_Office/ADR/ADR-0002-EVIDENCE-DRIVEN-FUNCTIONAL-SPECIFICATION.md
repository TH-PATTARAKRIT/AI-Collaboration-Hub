# ADR-0002: Evidence-Driven Functional Specification Standard
Status: APPROVED
Decision:
All SMEsPlus Functional Specifications must be created from traceable evidence.
Rule:
No Evidence Reference = No Functional Specification Approval.
Accepted Evidence:
- Source Code Analysis
- Database Dump / Schema
- BPMN
- Existing Documents
- Jira Epic / Story / Task
- API Specification
- UI / UX Design
- ADR
- SME / Owner Confirmation
Required FDS Section:
- Evidence Reference
- Evidence Assessment
- Functional Design Matching
- Gap Analysis
- Traceability
