# ADR-0003: As-Is Before To-Be Functional Design Standard
Status: APPROVED
Decision:
Functional Specification must analyze existing evidence before designing new functionality.
Mandatory Flow:
As-Is Evidence
→ Gap Assessment
→ To-Be Design
→ Jira Mapping
→ Claude Handoff
→ UAT
→ Review Gate
Classification:
- KEEP
- IMPROVE
- CREATE
- MERGE
- RETIRE
