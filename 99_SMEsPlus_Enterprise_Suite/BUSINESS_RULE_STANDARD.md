# Business Rule Template

| Field | Description |
|---|---|
| Rule ID | Unique business rule ID |
| Rule Name | Short rule name |
| Module | Related module |
| Business Purpose | Why the rule exists |
| Trigger | Event or condition that starts the rule |
| Condition | Logic or validation condition |
| Action | System or user action |
| Exception | Exception handling |
| Evidence | File or source reference |
| Status | NEW / PARTIAL / MATCHED / APPROVED / HOLD |
