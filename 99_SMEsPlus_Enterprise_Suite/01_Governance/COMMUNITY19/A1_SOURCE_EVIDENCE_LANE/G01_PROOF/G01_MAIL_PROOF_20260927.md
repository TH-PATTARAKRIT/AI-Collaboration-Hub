### 3.1 Refinements observed during execution (not new claims; no credit taken; for A3)

- **R1 (PC-39)**: the GIF request also sends the database name as the client key. That is outbound metadata that neither A1 nor A2 records.
- **R2 (PC-29)**: the activity docstring says "post access or write", but the executed mapping uses write. This explains A1's K1 wording and supports A2's refinement.
- **R3 (PC-28)**: on the unsubscribe page, the record link is hidden from logged-in users without read access, but the record name is always shown. The name disclosure (SF-07) is therefore unconditional.
- **R4 (PC-41)**: the scoped mention-token path is an OR alternative that internal users can also use, not only share users.
- **R5 (PC-25)**: the zip route's access is decided entirely outside the module. This makes base binary streaming a required cross-module proof dependency for PC-MAIL-04.
