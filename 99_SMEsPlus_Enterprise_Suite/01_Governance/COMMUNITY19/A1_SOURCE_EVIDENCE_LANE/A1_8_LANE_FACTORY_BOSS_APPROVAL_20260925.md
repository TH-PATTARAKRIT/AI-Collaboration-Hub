## Objective

## A1 8-Lane Factory
Each G may execute these logical lanes in parallel:
- A1-R — Roster / Module Membership / Manifest Integrity
- A1-M — Manifest / Dependencies / Module Purpose
- A1-D — Models / Fields / Data Identity / Constraints
- A1-B — Business Rules / States / Lifecycle / Exceptions
- A1-S — ACL / Groups / Record Rules / Company-Tenant Security
- A1-U — Menu / Action / View / Button / Wizard / Controller
- A1-J — Cron / Background Job / Configuration / Feature Toggle / Integration
- A1-X — Cross-Module Handoff / Contradictions / Tests / Reconciliation Candidates

An A1 Evidence Controller consolidates evidence pointers, SHA-256, deduplication, lineage, and completion-card status. It must not re-research unchanged evidence.

## Module Sharding
Module sharding is allowed only for exact governed roster members.
- Verified roster: distribute modules into non-overlapping logical shards and run applicable A1 lanes in parallel.
- Unverified roster: DO NOT infer or guess module names. Parallelize Roster Recovery, Controlled Evidence Search, Known Anchor Static Study, and Contradiction Investigation instead.

A module may be marked A1 COMPLETE only when every applicable field has verified evidence.
