# AI Repository Contract

Document ID: SMEPLUS-AIOS-REPO-CONTRACT-001
Status: Approved

## Purpose
This contract tells every AI role where to place outputs, how to name files, what evidence is required, and who must review the work.

## Mandatory Rule
AI must not guess repository, folder, file name, reviewer, or approval path.

If mapping is missing, stop and report: Repository mapping required.

## Standard Workflow
1. Read AI Project Constitution.
2. Read this Repository Contract.
3. Identify work domain and document type.
4. Check Repository Registry.
5. Check Folder Registry.
6. Check Naming Standard.
7. Generate deliverables.
8. Create evidence record.
9. Handoff to PMO AI and Technical Team AI.
10. Boss reviews when approval is required.

## Default Repository
Repository: TH-PATTARAKRIT/AI-Collaboration-Hub
Branch: SMEsPlus

## Evidence Rule
No Evidence equals No Progress.
Every output must include owner, source, timestamp, repository, folder, reviewer, and status.

## Authority
Specialist AI creates outputs.
PMO AI checks process and evidence.
Technical Team AI checks technical completeness.
Executive Secretary AI coordinates and prepares decision packs.
Boss gives final approval.
