# Preservation and publication rules

Status: Working navigation guidance
Owner role: Executive Secretary / Room A coordination
Review roles: PMO and Technical Team
Date: 2026-09-20

- Preserve existing file paths, historical statuses, evidence, branches and commit history.
- Distinguish current preparation from historical records through indexes, not deletion or unsupported relabelling.
- Do not change canonical counts, Function-IDs or STATE/gate status while organizing files.
- Stage changes in a separate branch and review them before any authorized merge.
- Do not publish restricted source, customer information, private workspace locations or research extracts to a public repository.
- Keep research writers, evidence reviewers and adversarial reviewers separate for each item.
- A review recommendation is not final approval.
- A file checksum proves identity, not correctness, completeness or clean-room eligibility.

No history was removed by this navigation change. Earlier records remain at their original paths and revisions.
